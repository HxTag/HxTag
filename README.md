## 🟢 About Me

I'm a Computer Science student focused on **AI/ML and Computer Vision**, with a practical, project-driven approach to software engineering. I enjoy building systems end-to-end — from real-time computer-vision applications using **OpenCV** and **MediaPipe**, to predictive ML pipelines with **XGBoost** and **Scikit-learn**, to full-stack web platforms built on **PHP, MySQL and WebSockets**.

My interest lies at the intersection of **applied machine learning** and **product engineering** — I like taking a model or an idea and shipping it as something usable, whether that's a Streamlit dashboard, a FastAPI service, or a collaborative web platform.

<summary><b>01 · Virtual Study Group</b></summary>

<details>
<summary><b>02 · Global Currency Exchange Rate Prediction</b></summary>

<br/>

A machine learning application that uses historical currency exchange-rate data to generate forecasts through trained predictive models.

| Category | Technology |
|---|---|
| Language | Python |
| Dashboard | Streamlit |
| API | FastAPI |
| Data Processing | NumPy, Pandas |
| Main Model | XGBoost |
| Baseline Model | Random Forest |
| Evaluation | MAE, RMSE, MAPE |
| Data Source | Frankfurter |

### Engineering Focus

The project builds lag-based and time-series features including moving averages, returns, momentum and volatility. XGBoost is used as the primary forecasting model while Random Forest provides a baseline for comparison. The application exposes predictions through a Streamlit dashboard and FastAPI endpoint.

🔗 **Repository:** [global-currency-exchange-rate-prediction](https://github.com/HxTag/global-currency-exchange-rate-prediction)

</details>

<details>
<summary><b>03 · Smart Eye Monitoring</b></summary>

<br/>

A real-time computer-vision application designed to monitor a person through a webcam and respond to visual conditions such as eye closure, movement away from the camera and face/hand positioning.

| Category | Technology |
|---|---|
| Language | Python |
| Computer Vision | OpenCV |
| Landmark Detection | MediaPipe |
| Numerical Processing | NumPy |
| Audio Alerts | Pygame |

### Engineering Focus

The application processes live webcam frames in real time, using MediaPipe's landmark detection to track facial and hand positioning, and triggers audio alerts via Pygame when defined conditions (such as prolonged eye closure or movement away from frame) are detected.

</details>
